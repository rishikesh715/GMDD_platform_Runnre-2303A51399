GEAR RUNNER - Unity package (2D mechanical platform runner)

INSTALL
1. Extract this zip.
2. Copy the "Assets" folder into your Unity project folder (merge when asked).
3. In Unity, wait for scripts to compile, then use the menu:
   Gear Runner > Create Game Scene
   (or manually: empty GameObject + add the GearRunner component to it)
4. Press Play.

NOTES
- No sprites/prefabs/physics needed: everything is generated at runtime.
- Works with the old Input Manager and the new Input System package.
- Needs Unity 2021 or later. Any render pipeline (Built-in/URP 2D).

CONTROLS
Space / Up = jump (twice = double jump)   Left/Right or A/D = move
Down or S = duck (needed for low crushers)
Mouse/touch: left edge = left, right edge = right, centre = jump, bottom centre = duck
